# viral-notes-generator

**脉脉 + 小红书爆文笔记生成器**

根据用户提供的话题或素材，自动生成适配脉脉和小红书平台的爆文笔记。

## 特性

- ✅ **双平台适配**：同一素材生成脉脉版 + 小红书版
- ✅ **爆文方法论**：内置平台特性和互动策略
- ✅ **标题优化**：提供 3 个标题选项 + 推荐理由
- ✅ **发布建议**：最佳发布时间 + 互动策略

## 触发条件

当用户提到以下关键词时触发：
- "脉脉笔记"、"小红书笔记"、"爆文笔记"
- "生成脉脉文案"、"生成小红书文案"
- "双平台笔记"、"职场爆文"

## 使用示例

### 基础用法

```
用户：帮我生成一篇关于「字节年终奖」的脉脉和小红书笔记

AI：
1. 分析话题特性（职场薪酬类）
2. 提取核心数据点（12 个月、4.5 个月、绩效差距）
3. 生成脉脉版（犀利职场风）
4. 生成小红书版（温暖分享风）
5. 提供发布建议
```

### 高级用法

```
用户：基于这篇文章生成双平台笔记：[粘贴原文]

AI：
1. 提取关键信息
2. 识别目标受众
3. 匹配平台调性
4. 生成优化版本
```

## 平台特性对比

| 维度 | 脉脉 | 小红书 |
|------|------|--------|
| **内容类型** | 职场干货 + 薪酬爆料 | 干货种草 + 信息分享 |
| **目标受众** | 互联网从业者、跳槽者 | 求职者、职场新人 |
| **情绪钩子** | 制造焦虑/讨论 | 制造希望/共鸣 |
| **互动目标** | 高评论率 | 高收藏率 |
| **互动策略** | 提问引发 debate | "收藏备用" + 干货列表 |
| **发布时间** | 工作日 12:00-13:00 或 20:00-22:00 | 晚上 19:00-21:00 或周末上午 |
| **语气风格** | 犀利、直接、数据驱动 | 温暖、分享、emoji 节奏 |

## 爆文方法论

### 核心公式

```
爆文 = 数字冲击 × 情绪共鸣 × 价值承诺 × 互动引导 × 可信背书
```

### 关键要素

1. **数字冲击**：对比数字制造冲击（12 vs 4.5）
2. **情绪共鸣**：脉脉焦虑/争议，小红书希望/共鸣
3. **价值承诺**：附跳槽建议、收藏备用
4. **互动引导**：评论区聊聊、收藏备用
5. **可信背书**：脉脉内部爆料、数据真实
