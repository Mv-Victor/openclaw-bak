# viral-notes-generator

**脉脉 + 小红书爆文笔记生成器**

根据用户提供的话题或素材，自动生成适配脉脉和小红书平台的爆文笔记。

## 触发条件

当用户提到以下关键词时触发：
- "脉脉笔记"、"小红书笔记"、"爆文笔记"
- "生成脉脉文案"、"生成小红书文案"
- "双平台笔记"、"职场爆文"
- "viral notes"、"platform notes"

## 核心能力

1. **双平台适配**：同一素材生成脉脉版 + 小红书版
2. **爆文方法论**：内置平台特性和互动策略
3. **标题优化**：提供 3 个标题选项 + 推荐理由
4. **发布建议**：最佳发布时间 + 互动策略

## 使用方式

### 基础用法

```
用户：帮我生成一篇关于「字节年终奖」的脉脉和小红书笔记

AI：
1. 分析话题特性（职场薪酬类）
2. 提取核心数据点（12 个月、4.5 个月、绩效差距）
3. 生成脉脉版（犀利职场风）
4. 生成小红书版（温暖分享风）
5. 提供发布建议
```

### 高级用法

```
用户：基于这篇文章生成双平台笔记：[粘贴原文]

AI：
1. 提取关键信息
2. 识别目标受众
3. 匹配平台调性
4. 生成优化版本
```

## 平台特性对比

| 维度 | 脉脉 | 小红书 |
|------|------|--------|
| **内容类型** | 职场干货 + 薪酬爆料 | 干货种草 + 信息分享 |
| **目标受众** | 互联网从业者、跳槽者 | 求职者、职场新人 |
| **情绪钩子** | 制造焦虑/讨论 | 制造希望/共鸣 |
| **互动目标** | 高评论率 | 高收藏率 |
| **互动策略** | 提问引发 debate | "收藏备用" + 干货列表 |
| **发布时间** | 工作日 12:00-13:00 或 20:00-22:00 | 晚上 19:00-21:00 或周末上午 |
| **语气风格** | 犀利、直接、数据驱动 | 温暖、分享、emoji 节奏 |

## 爆文方法论

### 1. 数字冲击
- 使用对比数字制造冲击（12 vs 4.5）
- 百分比增强说服力（20%-45%）
- 倍数放大差距感（差距 3 倍）

### 2. 情绪共鸣
- **脉脉**：同一起跑线，年终差距 3 倍（焦虑）
- **小红书**：互联网寒冬里的暖流（希望）

### 3. 价值承诺
- 附跳槽建议
- 收藏备用
- 干货列表

### 4. 互动引导
- **脉脉**：评论区聊聊、你怎么看
- **小红书**：评论区聊聊、收藏备用

### 5. 可信背书
- 脉脉内部爆料
- 数据真实
- 亲身经历

### 6. emoji 节奏（小红书专用）
- 每段开头 1-2 个
- 不密集堆砌
- 符合内容调性

## 生成流程

### Step 1: 分析话题

```
- 话题类型：职场薪酬 / 技能干货 / 行业爆料 / 求职经验
- 目标受众：互联网从业者 / 求职者 / 职场新人
- 核心数据：提取关键数字、对比点
- 情绪基调：焦虑 / 希望 / 共鸣 / 争议
```

### Step 2: 生成脉脉版

```markdown
## 标题（3 选 1）
A. [数字对比型]
B. [爆料型]
C. [真相揭秘型]

推荐：[理由]

## 正文
[犀利职场风，数据驱动，提问引发讨论]

## 发布建议
- 时间：工作日 12:00-13:00 或 20:00-22:00
- 互动：主动回复前 10 条评论
- 预期：高评论率
```

### Step 3: 生成小红书版

```markdown
## 标题（3 选 1）
A. [emoji + 数字冲击]
B. [干货种草型]
C. [经验分享型]

推荐：[理由]

## 正文
[温暖分享风，emoji 节奏，引导收藏]

## 发布建议
- 时间：晚上 19:00-21:00 或周末上午
- 互动：引导"收藏"关键词
- 预期：高收藏率
```

### Step 4: 输出对比表

| 维度 | 脉脉版 | 小红书版 |
|------|--------|----------|
| 标题风格 | 数字对比 | emoji + 干货 |
| 正文语气 | 犀利直接 | 温暖分享 |
| 互动目标 | 评论讨论 | 收藏转发 |
| 情绪钩子 | 焦虑/争议 | 希望/共鸣 |

## 质量检查清单

生成完成后，检查以下要素：

### 脉脉版
- [ ] 标题包含数字对比
- [ ] 正文有明确数据支撑
- [ ] 提出 2-3 个引发讨论的问题
- [ ] 语气犀利但不极端
- [ ] 话题标签 3-5 个

### 小红书版
- [ ] 标题有 emoji 且吸引眼球
- [ ] 正文 emoji 节奏合理（不密集）
- [ ] 包含"收藏备用"引导
- [ ] 语气温暖且有共鸣
- [ ] 话题标签 5-6 个

### 通用
- [ ] 数字准确可信
- [ ] 逻辑清晰连贯
- [ ] 价值承诺明确
- [ ] 发布建议具体

## 常见话题类型

### 1. 职场薪酬类
- 年终奖、涨薪、跳槽涨幅
- 大厂薪酬对比
- 绩效评定规则

### 2. 技能干货类
- 面试技巧
- 职场生存指南
- 技术栈选择

### 3. 行业爆料类
- 公司内幕
- 裁员消息
- 组织架构调整

### 4. 求职经验类
- 面试经历
- offer 选择
- 职业规划

## 注意事项

1. **数据真实性**：确保数据来源可靠，避免虚假信息
2. **平台规则**：遵守平台社区规范，避免敏感词
3. **情绪把控**：制造讨论但不煽动对立
4. **价值导向**：提供实用建议，不只是贩卖焦虑
