## Negative Prompt Library

### General Quality Issues
```
low quality, low resolution, blurry, pixelated, jpeg artifacts, compression artifacts, noise, grainy
```

### Unwanted Elements
```
watermark, text, signature, logo, username, copyright, border, frame
```

### Anatomical Issues (for characters)
```
deformed, distorted, disfigured, bad anatomy, bad proportions, extra limbs, missing limbs, mutated
```

### Style Conflicts
```
cartoon (for realistic), realistic (for cartoon), 3D (for 2D), 2D (for 3D)
```

### Composition Issues
```
cropped, cut off, out of frame, bad framing, cluttered, messy, chaotic
```

## Usage Tips

1. **Start Simple**: Begin with a clear subject, then add style modifiers
2. **Layer Enhancements**: Add quality, lighting, and composition enhancements
3. **Use Negative Prompts**: Specify what you don't want to avoid common issues
4. **Be Specific**: More specific prompts generally yield better results
5. **Test Variations**: Try different combinations to find what works best
6. **Consider Context**: Match style to content purpose (e.g., professional for business)
