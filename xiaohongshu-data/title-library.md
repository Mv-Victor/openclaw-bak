## 📊 标题公式

### 公式 1: 薪资数字 + 情绪表达
**模板**: `[公司/职级] 开出年薪 X 万，[情绪词]`
**案例**:
- "top3 本硕，拼多多开出年薪 68 万，有点犹豫"
- "小米这给的也太低了吧"
- "25*15 研发 没去"

### 公式 2: 大厂对比 + 打破滤镜
**模板**: `和 [大厂 A][职级] 的 [关系]，[大厂 B][职级] 的滤镜碎了`
**案例**:
- "和字节 3-2 的兄弟喝了顿酒，阿里 P7 的滤镜碎了"

### 公式 3: 情绪宣泄 + 求职话题
**模板**: `[情绪词]。[求职相关]`
**案例**:
- "你大坝的。春招秋招"

### 公式 4: 大厂动态 + 企业文化
**模板**: `[公司][高管] 发文，[具体事件]`
**案例**:
- "美团王兴发文，要求不许叫 x 哥 x 姐，要减少登味"

### 公式 5: 逆袭故事 + 经验分享
**模板**: `[起点] 逆袭 [终点]｜[内容类型]`
**案例**:
- "双非逆袭字节拼多多｜我的感悟分享！"
- "双非逆袭字节拼多多｜我的感悟分享！"

### 公式 6: 学历对比 + 就业结果
**模板**: `[学历背景]，[公司] 开出年薪 X 万，[情绪]`
**案例**:
- "top3 本硕，拼多多开出年薪 68 万，有点犹豫"

### 公式 7: 求职状态 + 数字量化
**模板**: `投了 X 份简历，[结果]`
**案例**:
- "投了三百份简历，offer 数量稳稳地锁死在 0"

## 📈 标题长度建议

- **最佳长度**: 15-25 字
- **最短**: 8 字 (如"小米这给的也太低了吧")
- **最长**: 40 字 (如"和字节 3-2 的兄弟喝了顿酒，阿里 P7 的滤镜碎了")

---

## 🔥 爆款标题特征

1. **具体数字**: 薪资、份数、人数等具体数字增加可信度
2. **情绪表达**: 直接表达情绪 (犹豫、碎了、太低) 引发共鸣
3. **对比反差**: 学历/公司/职级对比制造戏剧性
4. **打破认知**: "滤镜碎了"类内容满足好奇心
5. **身份认同**: "双非"、"26 届"等标签吸引同类人群
