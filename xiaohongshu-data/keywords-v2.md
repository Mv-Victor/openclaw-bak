## 爆款标题公式（2026-03-25 更新）

### 1. 情绪宣泄型
- "[状态] 工作 [时间] [情绪词]"
- 例："校招生工作一年半 燃尽了"
- 情绪词：燃尽、破防、挂麻、崩溃、疲惫

### 2. 反差冲击型
- "实际上 0 人会 [预期行为]"
- "[成就] 连 [权威角色] 都 [意外反应]"
- 例："实际上 0 人会祝福你秋招顺利拿 offer"
- 例："收到春招第一个 offer 连导师都沉默了"

### 3. 干货盘点型
- "[领域] 的所有 [资源/退路]"
- "[届别/时间][主题] 杂谈"
- 例："计算机类的所有退路！！"
- 例："26 届秋招各方向杂谈"

### 4. 争议话题型
- "[行业/领域] 正在上演 [隐喻]"
- "[身份] 想尝试 [概念]：求 [需求]"
- 例："互联网公司正在上演一场 AI 版的皇帝的新衣"
- 例："程序员想尝试'一人公司'：求高需求无人做 ide"

## 策略
1. 优先爬取争议性话题（评论数通常>500）
2. 关注"AI 工具 vs 传统方式"对比类
3. 数字化标题（"X 天"、"月入 X 万"）
4. 真实案例（面试/跳槽/副业收入）
5. **新增**：情绪宣泄型内容互动率最高（平均 400+ 评论）
6. **新增**："燃尽"、"破防"等情绪词触发强共鸣
