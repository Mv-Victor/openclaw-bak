## API 问题排查（早间任务）

### 问题
栋少反馈之前使用 Claude 中转 API 时出现：
- 常常没有回复消息
- "Unexpected event order, got message_start before receiving message_stop" 错误

### 根因
- xchai.xyz 返回的 SSE 事件流格式不完全符合 Anthropic Messages API 规范
- 事件顺序错乱（网络波动、响应超时、并发请求）
- OpenClaw 解析器严格校验，遇到非标准事件顺序时报错

### 解决
- 默认模型已切换为 `qwencode/qwen3.5-plus`（通义千问）
- 系统运行正常
