#### 2. 创建 nanobanana-image-gen 技能
由于无法访问 magicart.cc 网站（动态加载+浏览器不可用），基于对 Nano Banana Pro 的了解创建了增强版技能：

**位置**: `/root/.openclaw/workspace/skills/nanobanana-image-gen/`

**核心功能**:
- 10+ 种风格预设（photorealistic, illustration, anime, 3d-render, watercolor, oil-painting, minimalist, cyberpunk, fantasy, vintage）
- 7 种内容类型（cover, screenshot, social, story, banner, portrait, landscape）
- 自动 prompt 增强
- 质量预设（draft/standard/high/ultra）
- 支持多种宽高比（1:1, 16:9, 9:16, 4:3, 3:4, 21:9, 2.35:1）

**文件结构**:
```
nanobanana-image-gen/
├── SKILL.md                    # 技能文档（7.4KB）
├── scripts/
│   └── main.ts                 # 实现脚本（7.9KB）
└── references/
    └── style-library.md        # 风格库文档（11.3KB）
```

**风格库内容**:
- Photography Styles（5种）
- Illustration Styles（5种）
- 3D & Render Styles（3种）
- Painting Styles（4种）
- Modern & Design Styles（4种）
- Aesthetic Styles（5种）
- Fantasy & Sci-Fi Styles（3种）
- Vintage & Retro Styles（3种）
- Special Effects（3种）
- Prompt Enhancement Patterns
- Negative Prompt Library
- 使用技巧和示例

**使用示例**:
```bash
# 封面图
nanobanana-image-gen "AI technology article cover" --type cover --ar 16:9

# 截图
nanobanana-image-gen "Dashboard UI" --type screenshot --ar 16:9

# 社交媒体
nanobanana-image-gen "Product launch" --type social --ar 1:1

# 带风格
nanobanana-image-gen "A landscape" --style photorealistic --quality high
```
