## 直播自动切片方案调研

### 任务背景
栋少要求调研两个 GitHub 项目，设计一套支持抖音和 B 站的直播自动切片方案，要求无需 GPU 即可运行。

### 调研项目

#### 1. auto-slicing (zakahan)
- **核心**: ASR + LLM Agent + MCP 实现自动化录播视频切片
- **vedit-mcp 实现**: 
  - 基于 Python MCP SDK (`mcp.server.fastmcp.FastMCP`)
  - 底层使用 ffmpeg 进行视频操作（流复制，无重编码）
  - 核心工具：`clip_video_tool`, `merge_videos_tool`, `add_audio_to_video`
  - 路径管理：所有路径基于 `KB_DIR` 基准目录，避免 LLM 生成错误路径
- **ASR 方案**: SenseVoiceSmall 本地模型 或 火山方舟 API

#### 2. bilive (timerring)
- **无 GPU 配置**:
  - ASR: `asr_method = "api"` 使用 Groq Whisper API (free tier: 40MB/30min)
  - 切片：基于弹幕密度滑动窗口算法（CPU 实现，3 万条弹幕约 33 秒）
  - 处理模式：`model_type = "append"` 串行执行，兼容低配
- **硬件要求**: 最低 1 核 CPU + 2GB 内存即可运行
- **实测环境**: Oracle Cloud ARM (1 核 4G), Alicloud x64 (2 核 2G) 均验证可用

### 整合方案设计

#### 技术选型
| 模块 | 技术方案 |
|------|---------|
| 抖音录制 | yt-dlp |
| B 站录制 | blrec (bilive 子模块) |
| ASR 字幕 | Groq API (whisper-large-v3-turbo) |

| 视频切片 | vedit-mcp (ffmpeg) |
