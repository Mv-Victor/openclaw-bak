## 经验教训

1. **超时时间设置要充足**
   - 需要考虑网络请求、AI 总结等耗时操作
   - 23 篇文章 × (web_fetch + AI 总结) ≈ 15-20 分钟

2. **数据源稳定性**
   - RSSHub 等第三方源可能不稳定
   - 考虑备用方案（直接抓取 + 缓存）

3. **分步调试**
   - 数据抓取 → 数据处理 → 格式化输出 → 推送
   - 每一步都要有日志和错误处理
