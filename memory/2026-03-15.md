### 背景
- 栋少于 02:18 请求生成"机票最便宜的三个时间段"剪映工程文件

- 10:22 栋少询问进度和卡住原因

### 问题根因
1. **API endpoint 错误**: 原脚本使用 `/api/project/create`，实际应该是 `/api/project`
2. **projectId 类型错误**: API 要求 `Long` 类型，原脚本使用字符串 `"flight-ticket-cheap-times"`
3. **缺少必需字段**: `imageId`、`audioId` 等字段未提供
4. **素材未同步到容器**: 素材文件在宿主机，未复制到 Docker 容器内

### 解决方案
1. 修复 API endpoint 为 `/api/project`
2. 使用数字 projectId (200001)
3. 为每个素材添加唯一 ID (imageId, audioId)
4. 使用 `docker cp` 将素材复制到容器内 `/app/doc/sale/flight-ticket-cheap-times/`

### DreamX API 规范（已验证）
```
POST /api/project
- projectId: Long (必需，数字类型)
- projectName: String
- width: Integer (1080)
- height: Integer (1920)

POST /api/project/image
- projectId: Long
- imageId: Long (必需，唯一 ID)
- imageUrl: String (file:// 协议)
- startTime: Long (ms)
- duration: Long (ms)
- zoomX/zoomY: Integer (10000=100%)
- positionX/positionY: Integer

POST /api/project/audio
- projectId: Long
- audioId: Long (必需，唯一 ID)
- audioUrl: String
- startTime/duration: Long
- materialTimeStart/materialTimeEnd: Long (必需，否则 NPE)
- volume: Integer (-100~100)
- fadeInDuration/fadeOutDuration: Integer

POST /api/project/text
- projectId: Long
- text: String
- startTime/duration: Long
- positionX/positionY: Integer (Y 轴：上正下负，底部=750, 顶部=-800)
- asSubtitle: Boolean
- style: Object { fontSize, fillColor, strokeColor, strokeWidth, bold, textAlign, fontName }

POST /api/project/build
- projectId: Long
```

### 坐标系规范
- **Y 轴**: 上正下负，中心为 0
- 顶部居中：`positionY = -800`
- 底部居中：`positionY = 750`
- 水平居中：`positionX = 0`
