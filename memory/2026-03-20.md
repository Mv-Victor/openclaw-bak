## RSS 每日摘要 - GitHub Trends 问题修复

### 问题
栋少反馈 RSS 摘要中很少有 GitHub Trends 内容。

### 根因
- OPML 文件 (`/root/.openclaw/workspace-g/rss/feeder-dongshao.opml`) 中，GitHub Trending 订阅源在 `📈 Trends` 分类下
- 脚本 (`/root/.openclaw/workspace-g/rss/scripts/rss-daily-digest.py`) 的 `CATEGORIES` 配置期望的是 `⭐ GitHub Trends` 分类
- 分类不匹配导致 GitHub Trends 内容被过滤掉

### 修复
1. 添加 `SOURCE_TO_OUTPUT_CATEGORY` 映射表，处理源名称到输出分类的特殊映射
2. 修改 `fetch_all_feeds` 函数，优先使用映射表而非 OPML 分类
3. 简化 `format_daily_digest` 函数，直接按 `CATEGORIES` 定义的顺序输出

### 验证
手动执行脚本，确认 GitHub Trends 内容正确输出（5 条）：
```

### 1. opendataloader-project/opendataloader-pdf
### 2. langchain-ai/open-swe
### 3. obra/superpowers
...
```
