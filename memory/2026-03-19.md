### bilive 项目信息
- GitHub: https://github.com/timerring/bilive
- 功能：B 站直播录制、自动切片、弹幕渲染、字幕识别、自动上传
- 项目路径：/root/bilive/
- 架构：支持 amd64 和 arm64

### 配置要点（CPU 版本）
1. **ASR 字幕识别**：
   - `asr_method = "none"` 或 `"api"`（CPU 版本不用本地部署 whisper）
   - 如用 API：`asr_method = "api"` + `whisper_api_key`（Groq free tier）

2. **自动切片**：
   - `auto_slice = true`
   - `mllm_model = "qwen"`（或其他支持的模型）
   - 需要配置对应 API key

3. **直播间配置**（settings.toml）：
   - 需要获取邵艾伦 Alan 的直播间 ID
   - 添加到 `[[tasks]]` 列表

4. **B 站上传配置**：
   - 需要配置 B 站 cookie（`header.cookie`）
   - 使用 bilitool 进行持久化登录
